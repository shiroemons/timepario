# TimePario

World clocks, side by side.

アナログ時計と24時間表示のデジタル時計で、最大3地域を比較する軽量な世界時計です。表示する地域と順序は URL で共有できます。

## セットアップと開発

Node.js 24 LTS と pnpm 11.19.0 を使用します。

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium firefox webkit
pnpm dev
```

`http://localhost:8787` を開いてください。開発サーバーはブラウザー用アセットの初回ビルド完了後に起動します。TypeScript / CSS の変更を監視して再ビルドするため、変更後はブラウザーを再読み込みしてください。

```sh
pnpm typecheck
pnpm lint
pnpm test
pnpm test:e2e
pnpm build
pnpm size
```

`build:client` は esbuild によるブラウザー用 JS / CSS、`build:worker` は Wrangler の dry run による Worker 用ビルドです。`build` は両方を実行します。本番ビルドだけでは公開されません。

## URL の使い方

`/` はブラウザー・端末に設定されたタイムゾーンを表示します。物理的な現在地の推定や位置情報の取得は行いません。自動判定だけでは URL は変わりません。「リンクをコピー」は判定した地域を明示するURLをクリップボードへコピーします。成功するとボタン内に「コピーしました」と表示します。コピーできない環境ではURLを選択したダイアログが開き、手動でコピーできます。

| 識別子 | タイムゾーン | 意味 |
| --- | --- | --- |
| `jst` | `Asia/Tokyo` | 日本時間 |
| `pst` | `Etc/GMT+8` | **UTC−08:00 固定** |
| `pt` | `America/Los_Angeles` | 米国太平洋時間、夏時間に追従 |
| `utc` | `UTC` | 協定世界時 |
| `et` | `America/New_York` | 米国東部時間、夏時間に追従 |

例:

```text
/jst,pt,utc
/pst,pt
/jst,Asia~Kathmandu
/Europe~London,America~Argentina~Buenos_Aires
```

IANA 名のすべての `/` を `~` に置き換えます。短縮名は大文字・小文字を区別せず、小文字へ正規化します。定義済みの IANA 名も対応する短縮名になります。同一の地域は最初の指定を残し、異なる地域は現在の時差が同じでも統合しません。`CST` や `IST` の意味は推測しません。

重複を除いて4件以上、不明な地域、空要素、不正なエンコードは HTTP 400 です。指定を黙って削除したり UTC に置き換えたりしません。

追加・変更・削除・並べ替えは URL とブラウザー履歴に反映されます。「戻る・進む」で復元でき、`/` へ戻ると端末設定を再判定します。設定を localStorage や Cookie に重複保存しません。

時計のつまみをマウスやタッチでドラッグして表示順を変更できます。ドロップの確定時にだけURLと履歴を更新し、Escape・キャンセル・時計領域の外へのドロップでは変更しません。矢印ボタンでも並べ替えできます。

並べ替えの矢印は、PCで時計が横に並ぶときは左右、スマートフォンで縦に並ぶときは上下を向きます。

ドラッグ中は持ち上げたカードがマウスや指に追従し、移動先を強調します。確定後は離した位置からカードが新しい位置へ収まります。端末の「視差効果を減らす」などの設定では直接のドラッグ追従を維持し、拡大や確定後のアニメーションを抑えます。

「時差の基準」で表示中の時計を選ぶと、各カード下部に基準からの時差を表示します。UTC時差の表示は維持し、30分・45分の差や夏時間にも追従します。基準選択はそのページ内だけの比較操作です。並べ替えでは維持され、基準の時計を削除・変更した場合やページを再読み込みした場合は未選択に戻ります。

タイムゾーン選択では候補名に `(JST)` や `(PST)` などの略称を併記し、現在のUTC時差を右寄せで表示します。`pt` の略称は夏時間中にはPDT、それ以外はPSTです。略称でも検索でき、曖昧な略称の検索結果から具体的な地域を選べます。地域や実行環境によっては略称がGMT形式になる場合があります。

文字盤の色とラベルで各地域の深夜・朝・昼・夕方・夜を区別します。深夜は00:00〜04:59、朝は05:00〜11:59、昼は12:00〜15:59、夕方は16:00〜18:59、夜は19:00〜23:59を目安にし、秒更新や画面復帰時に再判定します。夕方は落ち着いたオレンジ系、深夜は夜より濃い紺色で表示します。実際の日の出・日の入りの表示ではありません。

## 全画面の時計表示

右上の「拡大表示」は、ブラウザーのウィンドウ内で同じ大きな時計表示へ切り替えます。ブラウザーの全画面機能は使いません。Escapeまたは「通常表示に戻る」で終了できます。

右上の「全画面表示」ボタンで、暗い背景に1〜3時計を大きく表示します。地域・日付・UTC時差・時間帯と、選択済みの基準との時差を維持します。編集操作は隠れ、3秒間操作しないと終了案内とカーソルも隠れます。マウスやキーボード操作で再表示し、Escapeまたは「全画面表示を終了」で通常表示へ戻ります。

ブラウザーが全画面を許可しない場合は、案内を表示してウィンドウ内で拡大します。小さい画面や文字拡大時には縦スクロールできます。OSのスクリーンセーバーへの登録や、端末のスリープ防止は行いません。

## PWAとして使う

対応ブラウザーのインストール操作から、TimeParioを独立したアプリウィンドウで開けます。Chrome / Edgeではアドレスバーやメニューのインストール操作、Safariでは「Dockに追加」や「ホーム画面に追加」を利用します。インストール方法はブラウザーとOSによって異なります。[MDNのインストール案内](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

初回はオンラインで読み込み、オフライン用データの準備を完了させてください。その後はオフラインで再読み込みしても時計を表示できます。地域は引き続きURLで指定し、アプリアイコンからの起動は端末のタイムゾーンを表示します。オフライン用キャッシュは設定保存とは独立しており、ブラウザーのサイトデータ削除で消去されます。

公開時にはHTTPSが必要です。ローカル開発では `localhost` または `127.0.0.1` を利用できます。ブラウザー内プレビューではインストール機能が提供されない場合があるため、インストール時は対応する通常のブラウザーで開いてください。

## リンクのプレビュー

共有リンクのHTMLにはOpen GraphとTwitter Cardを出力します。タイトルと説明には選択した地域名を反映し、共通の1200×630画像を使います。画像URLとcanonical URLはアクセス先のオリジンから生成するため、本番のホスト名をコードへ埋め込む必要はありません。不正URLと内部のオフライン画面は検索対象外にします。

実際のSNSでプレビューを取得するには、外部からアクセスできる公開URLが必要です。ローカルの `127.0.0.1` は外部クローラーから参照できません。

## 表示言語

ブラウザーの優先言語から日本語・英語を自動選択します。未対応の言語だけが指定されている場合は英語で表示します。サーバーの初期HTMLは `Accept-Language`、ブラウザーでの表示は `navigator.languages` を参照します。言語に合わせてUI・日付・説明・操作通知を切り替えます。

言語はタイムゾーンと独立しています。同じ `/utc,jst,pt` を共有しても、閲覧者の優先言語で表示され、地域と順序は変わりません。言語切り替えのためのCookie・localStorage・翻訳ライブラリは使用しません。地域名はUnicode CLDRの日本語都市名データを同梱し、都市名・英語名・IANA名・略称で検索できます。IANA名は識別用に原文も併記します。

## 時刻の基準と制約

- 表示は端末のシステム時刻に基づき、標準時との同期を保証しません。時刻取得 API や定期的なネットワーク通信は使いません。
- 夏時間など地域の時刻ルールは `Intl.DateTimeFormat` に任せるため、実行環境のタイムゾーンデータにも依存します。
- `pst` は通年 UTC−08:00、`pt` は Los Angeles の地域ルールに従います。夏時間中も URL は `pt` のままです。
- サーバーとブラウザーで対応する地域が異なる場合、表示できない時計に理由を表示します。
- 自動判定失敗時だけ UTC にフォールバックし、その理由を示します。JavaScript 無効時には利用に JavaScript が必要なことを表示します。

## 設計

- `src/shared/`: URL の解析・検証・正規化・生成、候補、日時変換。サーバーとブラウザーで共用します。
- `src/server/`: Hono / `hono/jsx` による HTML とエラー応答。
- `src/client/`: 標準 DOM API による時計・操作、SVG と CSS。ハイドレーションやフロントエンドフレームワークは使いません。
- アプリ名は `src/shared/config.ts`、UI 文言は辞書へ集約しています。表示言語とタイムゾーンは独立しており、日本時間を選んだことを理由に UI 言語は変わりません。
- 1回の描画で同じ現在時刻をすべての時計へ渡し、同じ日時データから針と数字を更新します。次の秒境界に更新を予約し、非表示時に停止、復帰時に再計算します。
- `Intl.DateTimeFormat` は地域・ロケールごとに再利用します。数値計算は `h23` / `latn` と `formatToParts()` を使用します。
- 選択候補は `Intl.supportedValuesOf('timeZone')` を利用し、未対応環境は主要候補へフォールバックします。候補にない有効な IANA 名も入力できます。
- HTML は `no-store`、Static Assets が JS / CSS を直接配信します。HTMLが参照するアセットには内容に基づくバージョンを付け、Service Workerは同じ版をキャッシュします。オンラインで存在しないアセットは404です。通信できない場合の画面遷移に限り、共通のオフライン画面からURLを復元します。
- CSP でスクリプト・スタイルを同一 origin に制限し、URL の値を生の HTML として挿入しません。

## Cloudflare Workers へのデプロイ

公開URL: [TimePario](https://timepario.shiroemons.workers.dev)（2026-09-12公開）。

Cloudflare アカウントと Workers へのデプロイ権限が必要です。必要に応じて `wrangler.jsonc` に対象アカウントの `account_id` や独自ドメインの `routes` を設定してください。プロジェクト名は `timepario` です。DB / KV などのリソースは不要です。

```sh
pnpm exec wrangler login
pnpm deploy
```

CI などでは `CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` を環境変数として設定できます。認証情報をリポジトリへ保存しないでください。
