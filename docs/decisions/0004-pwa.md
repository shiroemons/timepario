# ADR 0004: インストールとオフライン表示

状態: 採用・検証済み（2026-09-12）

## 方針

- manifestでアプリ名・アイコン・起動URL・standalone表示を定義する。インストールにはブラウザー標準の操作を使い、自動でダイアログを開かない。
- 起動時は端末のタイムゾーンを表示する。地域と順序は従来どおりURLで保持し、新しい設定ストレージは追加しない。
- 初回オンライン読み込み時にアセットと共通のオフライン画面を保存する。オフラインでも実際のURLを解析して時計を復元し、未訪問の地域URLや不正URLもブラウザーで処理する。
- HTMLの取得はネットワークを優先し、通信不能時にオフライン画面を使う。オンラインの400/404応答を成功画面に置き換えない。
- アセットにはビルド内容に基づくバージョンを付け、オフライン画面と同じ版を保存する。別バージョンのアセットや無関係なリクエストを古いキャッシュで代用しない。
- キャッシュ削除はTimePario自身の旧バージョンだけに限定する。開いているアプリを強制的に再読み込みしない。
- 時計は従来どおり端末時刻とIntlで計算し、時刻取得API・定期ポーリング・バックグラウンド同期・通知は追加しない。
- PWA用に同一オリジンのmanifest・worker・初回アセット取得を許可する。外部通信や新しい依存ライブラリは追加しない。
