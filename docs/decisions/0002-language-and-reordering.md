# ADR 0002: 優先言語での表示とドラッグによる並べ替え

状態: 採用（2026-09-12）

## 背景

初期版完成後、アクセスしたブラウザーの言語に合わせた表示、アイコンと文字の縦中央揃え、ドラッグ＆ドロップによる並べ替えが依頼された。

## 決定

- 初期版の英語固定を日本語・英語の自動選択へ拡張する。未対応の優先言語のみの場合は英語へフォールバックする。
- サーバーではAccept-Languageの重み付き優先順位を扱い、ブラウザーではnavigator.languagesを参照する。言語選択はリクエスト／ページ単位で保持し、共有URLのタイムゾーン識別子には混ぜない。
- URLの解析・正規化・日時の数値計算は言語に依存させない。翻訳は表示層と辞書で行う。サーバーエラー画面やJavaScript無効時の説明も翻訳する。
- 日本語の地域名はUnicode CLDRの都市名を同梱する。少数都市だけの個別訳をやめ、地域の別名にも対応する。データの出典・取得コミット・ライセンスを保存し、翻訳のための外部通信やライブラリは追加しない。
- 文字の記号をアイコンとして使う代わりに、同じviewBoxのSVGをサーバーとブラウザーで共用する。ラベルとSVGをflexの縦中央揃えで配置する。
- ドラッグはPointer Eventsを使い、マウス・タッチ・ペンを同じ処理で扱う。専用つまみだけを操作領域とし、通常のスクロールや文字の選択を妨げない。
- 並べ替えの履歴追加はドロップ成功時のみ。キャンセル時は変更しない。既存の矢印ボタンと通知を維持し、ドラッグ操作に依存させない。
- ドラッグ中のカードと移動先を影・輪郭で強調し、確定時はカードの前後の位置から短い移動アニメーションを付ける。時計の更新や状態の確定をアニメーション待ちにしない。`prefers-reduced-motion` では動きを抑える。
- 持ち上げたカードは、つかんだ位置を維持してポインターの横・縦の移動へ追従する。並べ替えの確定までは元の配置枠を維持し、移動したカード自身で移動先の判定を遮らない。離した位置から確定位置へ収める。動きを減らす設定でも直接のドラッグ追従は維持し、装飾的な拡大・確定後のアニメーションだけを抑える。
- 時差の比較基準は表示中の時計から選ぶ。毎回同じ瞬間のUTCオフセット同士を引き、24時間で丸めず符号付きの時間・分で表示する。カード下部の補助情報として表示し、UTC時差と時間帯ラベルを維持する。選択はページ内の一時的な比較操作とし、URLや永続ストレージには追加しない。並べ替えでは維持し、基準の地域がなくなれば未選択へ戻す。
- 候補のUTCオフセットは右寄せで比較できるようにする。略称は候補名の括弧内へ表示し、固定PSTと現在の地域略称を区別する。一般地域の略称はIntlの短い地域名を使用し、環境によってGMT形式になる場合も許容する。
- 深夜・朝・昼・夕方・夜は各地域の壁時計時刻で判定する。深夜は00:00〜04:59、朝は05:00〜11:59、昼は12:00〜15:59、夕方は16:00〜18:59、夜は19:00〜23:59。色だけに依存せずラベルも表示する。夕方は落ち着いたオレンジ系、深夜は夜より濃い紺色にする。日の出・日の入りの推定は行わない。
