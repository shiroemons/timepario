# ADR 0003: 全画面の時計表示

状態: 採用（2026-09-12）

## 背景

PCで最大化ボタンを押すと、スクリーンセーバーのように時計を大きく眺められる表示が依頼された。

## 決定

- ユーザーのボタン操作からFullscreen APIを呼び出す。利用できない場合や申請が拒否された場合は理由を案内し、ウィンドウ内で同じ時計表示を提供する。
- 追加依頼により「拡大表示」を独立した操作として提供する。この操作ではFullscreen APIを呼ばず、ブラウザーのウィンドウ内で同じ時計レイアウトを使う。終了後はそれぞれの開始ボタンへフォーカスを戻す。
- 背景を暗くし、地域名・アナログ時計・デジタル時計を中央に大きく配置する。時間帯ごとの文字盤の配色と基準からの時差を引き継ぐ。
- 表示中は追加・削除・並べ替えなどの編集操作を隠す。時計の状態・URL・比較基準・時刻更新の仕組みは切り替え前と共用する。
- 終了ボタンとEscapeの案内は3秒間の無操作で隠す。ポインターやキーボード操作で再表示し、終了ボタンにフォーカスがある間は隠さない。
- 終了ボタン・Escape・ブラウザーによる全画面解除を扱い、通常表示と開始ボタンへのフォーカスを復元する。申請中のキャンセルで遅れて全画面になった場合も解除する。
- 時刻更新用タイマーは追加しない。非表示中は無操作判定のタイマーも停止する。
- デスクトップでは1〜3時計を画面内へ配置し、小画面・文字拡大時には情報を切らず縦スクロールを許可する。
- OSのスクリーンセーバー登録・Wake Lock・自動全画面化は対象外とする。追加依存や外部通信は導入しない。
